Every export shipment lives in ten places: a tracker spreadsheet, the ERP, a shared drive, three inboxes and someone's memory.

EOT-PCS puts it in one controlled record, from proforma invoice to payment closure.
→ Oracle stays the read-only source of truth. Nothing is re-keyed.
→ Rules decide which documents each shipment needs.
→ Incomplete packages can't be submitted.
→ The person who prepared a package can never approve it.
→ Balances are tracked against invoices, and escalations run themselves.
→ Every action is in an append-only audit log.

We're running EOT-PCS as a pilot. If you run export operations and want to see it on your own document rules, comment "walkthrough".
