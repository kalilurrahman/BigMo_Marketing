# BigMo: post text for every asset

Copy-paste text to go with each file in `output/`. Each block has the text exactly as it should be posted (line breaks included), then any first comment, alt text and notes.

**House rules for every BigMo post**
- Say "seven products we build", never "seven launched products". EOT-PCS is a **pilot** and Ledger Book is in **early access**.
- No user numbers, revenue, growth or customer logos.
- On LinkedIn the first ~210 characters show before "…see more", so the hook goes there.
- Put the link in the **first comment** on LinkedIn (posts with links in the body get less reach). On Instagram, say "link in bio".
