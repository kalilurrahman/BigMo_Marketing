## ⚙️ Campaign Kit Architecture & Tools

Each campaign folder contains reproducible build scripts, brand tokens, copy definitions, and assets:

- **`tools/socialkit.py`**: Core Pillow + ffmpeg layout & video generator (browser/phone frames, typography, eased push-in animations, cross-fades).
- **`tools/platforms.py`**: Platform banner & header standardizer (X, LinkedIn, Facebook, YouTube).
- **`tools/phase2.py`**: Month-two marketing asset builder (myth-vs-fact carousels & feature deep-dives).
- **`tools/longcut.py`**: Narrated 45–60s explainer video builder with burned-in subtitles and voiceover timing.

### Building Campaigns Locally

```bash
# Install Pillow dependency (ffmpeg must be available on PATH)
pip install pillow

# Build an individual campaign
python3 campaigns/lakshyaprep/build.py --src ../academy-kpm-spark

# Build platform headers across all products
python3 tools/platforms.py

# Build month-two assets
python3 tools/phase2.py
```
